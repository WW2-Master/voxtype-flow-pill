# Third-party code

`quickshell/` contains the Quickshell frontend shipped with Voxtype 1.1.0,
copyright Peter Jackson and contributors, under the MIT License reproduced in
`LICENSE`.

Local changes to that frontend add capsule pointer input and a short exit
delay in `OsdSurface.qml`, and an explicit audio bridge binding in `shell.qml`.
The style, preview, installer, and project documentation were added for this
project.

Upstream: https://github.com/peteonrails/voxtype
